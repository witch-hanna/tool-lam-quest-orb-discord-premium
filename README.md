# 🐱 Witch Hanna — Discord Quest Tool

Tool treo nhiệm vụ Discord 15 phút siêu nhẹ (chỉ 5 KB mỗi game, không cần tải game nặng về máy).

### 📥 Cách tải và sử dụng
1. Tải file **[Witch-Hanna-Quest-Tool.zip](Witch-Hanna-Quest-Tool.zip)** về máy.
2. Chuột phải chọn **Extract All (Giải nén)**.
3. Mở **DiscordQuestTool.exe**, chọn game cần làm nhiệm vụ và bấm **Bắt đầu treo Quest**.
